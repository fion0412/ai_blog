14 CHAPTERS · DETAILED OUTLINE

详细课程内容

点击每章可查看学习目标与具体练习主题。实际练习会根据上课形式、现有工具权限与学员目标安排。

第一章Codex 入门与智能体基础＋

先认识 Codex 的工作方式，再把一个实际需求拆成可以执行、检查与修订的任务。

  • 认识 Codex 与 AI Agent 的基本概念
  • 写清任务目标、素材、限制与输出格式
  • 从一个小任务建立首个可复用流程
第二章用 Codex 搭建全球资讯热点源＋

把资讯搜集变成可审核的选题流程，保留来源与发布时间。

  • 设置关注的主题、地区和信息来源
  • 整理热点摘要与候选选题
  • 核对来源后再用于公众号或短视频
第三章Codex 自动化内容工厂：公众号／小红书＋

从选题到草稿、配图与排版，设计有人审核的内容生产流程。

  • 建立写作专用 Skill 与内容模板
  • 制作封面及正文插图，整理排版
  • 准备公众号草稿和小红书内容，发布前人工复核
第四章Codex 自动化视频工厂：数字人／口播＋

围绕脚本、角色、配音和画面建立可重复使用的口播制作步骤。

  • 编写视频提示词与口播脚本
  • 了解数字人及营销视频的制作流程
  • 检查肖像、声音与素材使用授权
第五章Codex 自动化视频工厂：生成／剪辑＋

学习将分镜、素材生成、剪辑与导出串成一条完整视频流程。

  • 认识 HyperFrames、Remotion、ChatCut 等制作思路
  • 规划播客、电商或旅游短片的分镜与素材
  • 检查字幕、节奏、版权和最终成片
第六章Codex 完成自动化高效办公＋

让 AI 协助整理资料、制作文件与复用常见办公步骤。

  • 读取文件、提炼重点并准确修改原稿
  • 批量整理资料、格式转换与制作可编辑 PPT
  • 处理数据分析、写作和个人助理场景
第七章Codex 图形生产力：多场景应用＋

用结构化图像需求提高视觉内容的一致性和可修改性。

  • 整理电商主图与详情页的内容需求
  • 设计公众号封面、金句插图与海报
  • 检查图像尺寸、文字和商用授权
第八章用 Codex 搭建和部署个人／企业网站＋

从需求、内容和页面原型开始，学习建立并发布一个简易网站。

  • 梳理介绍、服务、案例与常见问题
  • 制作可评审网页原型并在本地检查
  • 认识 GitHub 部署及上线后的更新步骤
第九章用 Codex 零基础开发小程序＋

从一个明确使用场景出发，规划简单功能并验证操作流程。

  • 确定用户、核心功能与输入输出
  • 制作可演示原型并测试关键步骤
  • 记录后续修改和部署需求
第十章用 Codex 连接飞书 Lark 自动化办公＋

认识平台连接、权限与数据结构，设计可审计的业务流程。

  • 了解飞书 Lark 连接方式与权限范围
  • 规划销售统计、客户管理等场景
  • 整理电商数据看板与报告流程
第十一章Codex＋Obsidian 搭建本地知识库＋

把分散资料整理为可检索、可维护的个人或团队知识工作台。

  • 规划文件夹、笔记结构与知识关联
  • 理解检索增强与资料引用的基本思路
  • 用于内容生产和客户项目资料管理
第十二章用 Codex 搭建自用智能体客服＋

从现有业务资料开始，规划问答范围、错误处理与人工交接。

  • 整理常见问题与标准答案
  • 设计知识库查询和回复规则
  • 测试无法回答、敏感信息与转人工场景
第十三章用 Codex 完成电商行业应用＋

根据电商流程挑选适合自动化的环节，先做小范围验证。

  • 梳理商品资料、上架与独立站内容
  • 规划营销视频和产品说明生成流程
  • 关注平台规则、商品事实与素材授权
第十四章Codex 常用插件／Skill 合集＋

按任务选择合适的工具和 Skill，并学习制作自己的可复用工作流。

  • 认识安装、使用与权限检查方法
  • 了解写作、调研、图像及电脑操作工具
  • 用 skill-creator 整理自己的任务流程
